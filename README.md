# 408 数据结构可视化演示网站（扩展增强版）

运行：

```bash
python app.py
```

浏览器打开：`http://127.0.0.1:5000`

## 本版新增/优化

- 构造二叉树与“构造后二叉树线索化”的示例改为高度 4 的复杂树。
- 新增数组与特殊矩阵：对称矩阵、三角矩阵、三对角矩阵、稀疏矩阵三元组表。
- 新增散列表：散列函数构造、线性探测、链地址法、冲突解决方法对比。
- 新增排序：基数排序、外部排序、多路平衡归并、败者树、最佳归并树、置换选择排序。
- 新增栈/队列：顺序循环队列、链式队列、双端队列、递归栈、括号匹配。
- KMP 改为更复杂的主串/模式串示例，并新增 nextval 优化演示。
- 线性结构新增：双链表、循环链表、静态链表动态演示。

页面结构仍然保持：左侧动态演示，右侧代码同步高亮，每一步附带 408 常考提醒。


## 本次更新：KMP next / nextval 对照推导
- 在 KMP nextval 演示中新增 next 数组对照行。
- 新增 lps（最长相等真前后缀长度）推导过程。
- 每一步展示当前子串的真前缀、真后缀、是否相等，以及 nextval 如何由 next 优化得到。


## 本次新增（内部排序比较表与 408 高频技巧）

- 新增“内部排序综合比较表”：覆盖直接插入、折半插入、希尔、冒泡、快速、简单选择、堆、归并、基数排序。
- 新增“排序选择题速判技巧”：按稳定性、最好/最坏复杂度、空间复杂度、存储结构、外部排序关键词进行判断。
- 新增 408 高频技巧模块：树与二叉树公式、图算法选型与复杂度、查找 ASL 与散列表计算、常考代码模板与易错顺序。
- 这些模块仍保持左侧动态演示、右侧代码高亮同步的形式。


## 本次新增：计算机组成原理专题

- 新增“计算机组成原理”目录，保持左侧动态演示、右侧代码/微操作同步高亮。
- 覆盖图中硬件部件：主存、MAR、MDR、ACC、MQ、X、ALU、PC、IR、CU，并给出 408 常考含义。
- 新增模型机演示：以 `ADD 200` 为例，逐步展示取指、译码、访存取操作数、ALU 运算、ACC 写回。
- 新增指令周期、数据通路与控制信号、主存容量计算、Cache 地址映射、补码溢出、浮点数规格化、I/O 中断与 DMA、CPU 性能公式与流水线。
- 新增“组成原理 408 高频速判技巧”，用于快速判断 MAR/MDR/PC/IR、Cache、补码、浮点数、中断、DMA 等常考题。

## v10 布局增强

- 动态演示区与代码同步区之间新增可拖动分隔条。
- 鼠标或触控左右拖动可调整两侧宽度，代码区最小宽度为 260px。
- 双击分隔条恢复默认比例；键盘聚焦分隔条后可用左右方向键微调。
- 用户调整后的宽度比例会保存在浏览器本地，下次打开继续使用。
